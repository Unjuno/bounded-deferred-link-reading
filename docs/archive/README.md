# Historical experiment notes

This directory contains short summaries and audits from earlier experimental phases.

They are preserved for provenance and for checking how the research interpretation changed, but they are **not the best entry point for the current conclusions**. For the current synthesis, use:

- [`../RESEARCH_SUMMARY.md`](../RESEARCH_SUMMARY.md)
- [`../EXPERIMENT_TIMELINE.md`](../EXPERIMENT_TIMELINE.md)
- [`../ANALYTIC_THEORY.md`](../ANALYTIC_THEORY.md)

Negative and failed experiments remain part of the record. Moving a file here does not change its scientific status or remove it from the repository; it only separates historical phase notes from the current synthesis documents.
